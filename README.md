## What Is This?

This is the **original portfolio site** — a clean, minimal Node.js + EJS app that introduced Vedant Sareen's cybersecurity work to the web. It was proof-of-concept for server-side rendered portfolios on Vercel before the full v2 redesign.

The codebase is deliberately simple: a single `server.js`, one `index.ejs` view, and static assets. No animations, no canvas, no admin — just the first step.

## Running Locally

```bash
git clone https://github.com/CYBERSAREEN/Portfolio.git
cd Portfolio
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)
